## Приоритет 1 — максимальный UX-эффект

- [x] **Переключатель типа графика — PER-CHART** (`ChartStyle: LINE/SMOOTH/AREA/BARS/DOTS`) — ГОТОВО
      Дропдаун «Вид графика» на КАЖДОЙ 2D-карточке (Темп/Аксел-1/Аксел-2/динамика),
      независимо. enum в `AppSettings`, состояние per-card в `rememberSaveable`.
      Рендер: `NeonChart.drawSeriesLine` (glow/ломаная), `drawSeriesBars`, `drawSeriesDots`,
      `buildSmoothPath(smooth=)`. 3D-облако и XY(orbit) — остались своими карточками.
      Фоллоу-ап: рестарт-персист per-card (сейчас только поворот); иконки в дропдауне;
      нижняя референс-строка «Доступные виды».
  - UX: ясность + производительность + скриншоты для отчёта. `MINIMAL` без glow
    (`BlurMaskFilter` дорогой) — чище и дешевле на слабых телефонах.
  - Как: поле `style` в `NeonChartConfig`; в `drawNeonChart` по стилю пропускать
    glow/fill/envelope/sigma. Сегментные чипы над слотом. Выбор → `rememberSaveable`
    + персист в настройки. Переиспользует оси/зум/crosshair — мало кода.
  - Файлы: `NeonChart.kt`, `GraphActivity.kt`, `GraphViewState.kt`/settings · Трудоёмкость: M
  - Готово: чипы переключают стиль в одном слоте; выбор переживает поворот и перезапуск.

- [ ] **Заморозка + скраб по истории**
  - UX: главная диагностическая фича — «отмотать к моменту удара», читать значения.
  - Как: пауза уже есть (`snapshotWhen`). Добавить ползунок-таймлайн поверх
    замороженного окна → курсор двигается, crosshair показывает значения.
  - Файлы: `GraphActivity.kt`, `NeonChart.kt` (crosshair), `SyncCrosshair.kt` · Трудоёмкость: M
  - Готово: на паузе ползунок водит курсор по всей записи, значения обновляются.

- [ ] **Режим оси Y: «общая» vs «по каждой серии»**
  - UX: чинит мёртвую полосу (T1~27 / T2~24 жмутся в ⅓ высоты, середина пустая).
  - Как: тоггл `fitEachSeries`; при включении — авто-диапазон на серию (мульти-ось
    или нормализация), при выкл — текущая общая ось.
  - Файлы: `NeonChart.kt` (`ChartBounds`/`niceAxis`), `GraphActivity.kt` · Трудоёмкость: M
  - Готово: тоггл переключает; в «по каждой» обе серии используют всю высоту.
